Rectangle

Very simple application made in C++ using the SFML library

**Dependencies**

- g++ with C++17 support
- SFML development libraries

Installing SFML (Debian/Ubuntu)
```bash
sudo apt install libsfml-dev
```

(Arch)
```bash
sudo pacman -S sfml
```

(macOS)
```bash
brew install sfml
```

**Building**
```bash
make
./main/rectangle
```

**Cleaning**
```bash
make clean
```
